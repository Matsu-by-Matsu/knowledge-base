🔄 更新手順ガイド

  • 01 Claude: このチャットで「マップ更新して」と送ると、最新スレッド一覧をJSON形式で出力してくれる。
  • 02 ChatGPT: 「今月の会話を以下のJSON形式でまとめて」と指示し、同じ形式のデータをもらう。source: "chatgpt"を付ける。
  • 03 マージ: 「データを更新」ボタンを押してJSONをコピー → data.jsファイルにペーストしてGitHubに保存。
  • 04 GitHub Pages: 保存後1〜2分でサイトに自動反映される。
  • 05 手動追加: サイドバーの「+ 新規追加」から任意のURLとメモを追加できる（ローカル保存）。
