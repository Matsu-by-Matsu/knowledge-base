🔄 更新手順
01Claude更新：「マップ更新して」と送ると最新JSONを出力。「↓ 取込」でペースト。
02ChatGPT更新：「↓ 取込」→ChatGPTタブ→プロンプトをChatGPTに送る→返却JSONをペースト。
03自動要約：各スレッドの「AI要約」ボタンを押すと、Claude APIがsummaryとhighlightsを自動生成。
04スコア設定：スレッド横の±ボタン、またはポップアップ内で0-10点を設定。高スコア順に自動ソート。
05GitHub保存：「⚙ GitHub設定」でToken設定後、「↑ 保存」で全デバイスに同期。

    ①プロンプトをコピー → ChatGPTに送る → ②返答JSONをペースト

    今月あなたと私が行った会話をJSON配列形式でまとめてください。各会話について: title(30文字以内), url(なければ""), category(不動産ビジネス/X・noteコンテンツ事業/新規ビジネス探索/テクノロジー学習/ライフスタイルから選択), subcategory, score(0-10の重要度点数), summary(200文字以内の詳細要約), highlights(重要ポイントの配列、3-5個), date(YYYY/MM/DD), source:"chatgpt"。JSON配列のみ出力。
    ⚙ GitHub連携設定
    GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
    スコープ: repo にチェック → Generate → コピー
    取得: console.anthropic.com → API Keys → Create Key（$5クレジット必要）
