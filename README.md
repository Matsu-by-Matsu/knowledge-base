# Matsu Knowledge Base

AIツール（Claude・ChatGPT・NotebookLM）の会話履歴を一元管理するパーソナルサイト。

## セットアップ
1. このリポジトリをGitHubに作成
2. Settings → Pages → Source: main branch / root
3. `https://{username}.github.io/{repo-name}` でアクセス可能

## 更新方法
1. サイト上の「データ更新」ボタンを押してJSONをコピー
2. `data.js` をそのJSONで上書き
3. GitHubにコミット → 自動反映（1〜2分）

## ChatGPT連携
サイト内「更新手順」ページにChatGPT用プロンプトが記載されています。
